# Audio Files

Drop your MP3 files in this folder (`audio/l1/` for Lesson 1) and register them
in `content/audio.js`.

## If a file is missing, the app automatically falls back to browser TTS.
You can add files one at a time — nothing breaks.

## Naming convention (suggested)

    l1_s3_par1_sen1.mp3     Lesson 1, section 3, paragraph 1, sentence 1
    l1_s4_par2_sen5.mp3     Lesson 1, reading, paragraph 2, sentence 5
    l1_s2_line_roya_1.mp3   Lesson 1, conversation, Roya's first line
    l1_s5_ex_past_01.mp3    Lesson 1, grammar example #1
    l1_s9_story_01.mp3      Lesson 1, review story line 1

## How to register a file

Open `content/audio.js` and add a line:

    "l1_s4_par1_sen1": "audio/l1/l1_s4_par1_sen1.mp3",

The key (`l1_s4_par1_sen1`) must match the `audioId` field in `content/lesson1.js`.

## Sound effects (correct / wrong)

Sound effects are generated by the browser (WebAudio). You do NOT need to
add MP3s for them.
